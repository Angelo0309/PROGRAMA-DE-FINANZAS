# Changelog

## 1.0.0-entrega-final - 2026-10-31

- Monorepo reproducible con API NestJS y frontend React.
- Motor financiero 30/360 probado con Decimal.
- Autenticacion Argon2id, JWT, sesiones rotatorias y aislamiento por tienda.
- Compras, obligaciones, cortes, pagos completos, auditoria y portales por rol.
- Bajas logicas auditadas y recorrido HTTP integral de activacion a comprobante.
- Importes cobrables presentados con redondeo HALF_UP a dos decimales.
- Imagenes de productos mediante URL HTTPS disponibles en catalogo e historial de compras.
- Catalogo web del negocio con busqueda, vista previa de imagen y alta de productos.
- Directorio web de clientes con saldos por cuenta y registro de nuevas identidades.
- Pantalla guiada de compras con multiples conceptos, imagenes y modalidades de fin de mes o cuotas.
- Gestion web de cuentas corrientes con limites, saldos y condiciones crediticias vigentes.
- Consulta web del cronograma oficial de cuotas, vencimientos, intereses y estados.
- Prisma, migracion, semillas ficticias, Docker, CI y guias de despliegue.
